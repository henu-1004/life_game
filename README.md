# 🌍 Project 1/8,000,000,000 (80억 분의 1) - PC 독립 실행형 게임

> **"지구라는 거대한 80억 분의 1 확률 생성기에서 태어나, 살아남고 선택하며 완주하는 탑다운 라이프 시뮬레이션"**  
> (RimWorld × The Sims × BitLife 스타일)

웹 브라우저가 아닌 **독립된 전용 PC 게임 윈도우 창**으로 실행되며, 림월드/심즈 스타일의 정교한 2D 탑다운 공간 조작, 6대 욕구 관리, 24시간 일과 스케줄러, 운명의 갈림길 선택지, 80억 통계 리포트가 모두 구현되어 있습니다.

---

## 🚀 게임 실행 방법 (가장 쉬운 방법)

1. **바탕화면에서 더블 클릭**:
   * 바탕화면에 생성된 **`80억분의1_인생게임.bat`** 파일을 더블 클릭하면 바로 전용 게임 창이 뜹니다.
2. **또는 프로젝트 폴더에서 실행**:
   * `게임_실행하기.bat` 더블 클릭!
   * 터미널에서는 `npm start` 입력 시 즉시 실행됩니다.

---

## 🎮 주요 게임 시스템

### 1. 2가지 게임 모드
* **🎲 80억 분의 1 무작위 스폰 모드**:
  * UN 인구 통계 비율 그대로 무작위 출생 (인도/중국 ~35.5%, 아프리카 ~18%, 한국 ~0.64%, 노르웨이 0.07% 등).
  * 부모 소득 5분위수(취약계층 ~ 초부유층) 및 선천적 유전 특성(수리천재, 강철체력, 병약함 등) 무작위 부여.
* **🏳️ 국가 직접 선택 (샌드박스) 모드**:
  * 한국, 미국, 일본, 독일, 노르웨이, 나이지리아, 소말리아 등 원하는 국가의 인프라 스텟(GDP, 기대수명, 영유아 사망률, 보건/치안 지수)을 확인하며 출생.

### 2. 림월드식 2D 탑다운 공간 & 직접 조작
* **가구 오브젝트**:
  * 🛏️ **침대**: 수면 (기력 고속 회복)
  * 📖 **책상**: 학업 및 연구 (지능 상승, 기력 소모)
  * 💻 **컴퓨터**: 게임 및 주식/부업 (재미/멘탈 회복, 자산 증식)
  * 🍔 **냉장고**: 식사 (허기 회복)
  * 🚿 **샤워실**: 청결 유지 (위생/멘탈 회복)
  * 🛋️ **소파**: TV 시청 및 휴식 (재미/멘탈 완충)
  * 🏢 **현관문**: 학교/직장 외출 (연봉 소득 획득)
* **플레이어 직접 명령**: 맵 위의 가구를 마우스로 클릭하면 캐릭터가 즉시 해당 가구로 이동해 강제 이용을 시작합니다.

### 3. 림월드식 24시간 일과 스케줄러 & 우선순위 AI
* 우측 상단 **[📅 24h 일과표]** 버튼을 눌러 24시간 루틴을 커스텀할 수 있습니다.
* 수면(Sleep), 공부/업무(Work/Study), 여가(Recreation), 자유시간(FreeTime)을 시간대별로 배정.
* 긴급 생체 욕구(탈진, 극심한 허기 등) 발생 시 우선순위 AI가 자율적으로 응급 대처를 수행합니다.

### 4. 시공간 압축 (1분 = 1년) & 핫키
* **기본 속도**: 1년 = 60초 (평균 수명 75세 기준 한 판당 약 20~30분 소요).
* **조작 핫키**:
  * `Spacebar`: 시간 일시정지 / 재개 토글
  * `1` 키: 1배속 (기본)
  * `2` 키: 2배속 (빠르게)
  * `3` 키: 4배속 (초고속)

### 5. 나이대별 운명의 갈림길 이벤트
* 3세(유아기 질병), 14세(사춘기 방황), 20세(진로/대학/창업), 38세(투자/자산 베팅), 62세(노년 건강 위기) 등 중요한 시점마다 **시간이 자동 일시정지**되며 팝업 선택지가 등장합니다.
* 성공 확률과 능력치/자산 변화가 실시간 반영됩니다.

### 6. 사망 및 인생 결산 리포트 (The 8-Billion Index)
* 영유아 사망률(1~3세) 및 노년 질병/자연사 판정.
* 사망 시 지구 80억 인류 기준 **누적 소득 백분위 그래프**, 출생국 기대수명 대비 장수 여부, **맞춤형 묘비명** 출력.
* 즉시 다시 80억 무작위 환생 또는 다른 국가 선택 가능!

## 🛠️ 기술 스택
* **Desktop Shell**: Electron (하드웨어 가속 독립 실행형 윈도우)
* **Renderer**: React 19 + TypeScript + HTML5 2D Canvas Engine
* **Styling**: Tailwind CSS + Lucide Icons + Pretendard Font
